# 音素材の差し替え手引き

**現在 `assets/sfx/` に入っている8ファイルは実音源です**（[効果音ラボ](https://soundeffect-lab.info/)の素材を加工）。
入っていないものは WebAudio の合成音で鳴ります。出典は [CREDITS.md](CREDITS.md)。

| 音 | 状態 |
|---|---|
| 足音 右／左／着地 | **実音源**（砂利の上を歩く。1歩ずつ切り出し済み） |
| 環境音（風） | **実音源**（18秒・継ぎ目クロスフェード済み） |
| 汽笛（照合開始） | **実音源**（大型船の汽笛・遠距離） |
| 警告 | **実音源**（サイレン） |
| 走査ビーム／処理音 | **実音源** |
| メトロノームのクリック | **廃止**（このゲームに拍を刻む音は無い） |
| 提示・追従フェーズの下敷き | 合成ドローン（拍を持たない音のみ。後述） |
| 結果ジングル 3種 | 合成音（未差し替え） |

差し替えは、このフォルダの `sfx/` に決まった名前で置くだけです。
拡張子は `.wav` → `.ogg` → `.mp3` の順に探し、無いものは合成音に落ちます。

## 加工ツール

元素材をゲームで使える形に整えるツールが `tools/prepare-audio.html` にあります。

```bash
node tools/savesrv.js          # 保存先サーバ（別ターミナルで）
python -m http.server 8123     # ツールを開くため
```

`http://localhost:8123/tools/prepare-audio.html` を開いて「加工して保存する」。
`.tmp/src/` の元素材から、頭出し・1歩ずつの切り出し・ループ化・音量統一・wav化までやります。
新しい素材に差し替えるときは、このファイルの「レシピ」の部分を書き換えてください。

## 拍を刻む音を入れないこと

**このゲームにメトロノームは無い。** クリックもカウントも鳴らしません。
リズムの手本は先導者の足音そのもので示します。
拍を刻む記号音が鳴った瞬間、画面は「リズムゲーム」になってしまうためです。

`bed_loop` を差し替える場合も、**拍のない持続音（ドローン／アンビエント）**にしてください。
リズムのある曲は、ラウンドごとにテンポが変わること（100→112 BPM）もあって二重に噛み合いません。

## 最重要の技術的注意（これを外すとゲームが壊れます）

### 1. 足音に mp3 を使わない

mp3 はエンコード時に **先頭へ数十msの無音が入る**（エンコーダ遅延）。
足音はこのゲームで唯一のリズムの基準なので、これをやると
**全プレイヤーが等しく数十ms遅れて叩くようになる**。
`step_*` は **wav（推奨）か ogg** にしてください。

### 2. 先頭の無音をゼロまで詰める

ダウンロードした素材はたいてい頭に 10〜80ms の余白があります。
Audacity なら、波形の立ち上がりの直前まで選択して削除 → 書き出し。
**この作業をやらないと、素材を良くしたのにリズムが取りづらくなります。**

### 3. 環境音（`wind_loop`）に周期性のあるものを選ばない

一定間隔で「ヒュッ」と鳴るような素材を選ぶと、プレイヤーがそれをメトロノーム代わりに使い、
このゲームの中核（無音で歩き続ける）が成立しなくなります。
のっぺりした持続音を選び、ループ点でプツッと切れないようクロスフェードしてください。

## 差し替えたあとの確認

`file://` で直接開くと fetch が CORS で失敗して**素材が読み込まれません**（合成音に落ちます）。
実音源を確認するときは必ずサーバ経由で:

```bash
python -m http.server 8123
```

読み込めているかはブラウザのコンソールで確認できます:

```javascript
SW.audio.loaded()
```

差し替わったファイル名の一覧が返ります。空配列なら1つも読めていません。
