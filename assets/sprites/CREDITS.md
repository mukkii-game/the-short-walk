# キャラクタースプライトのクレジット

`crowd.png` は LPC (Liberated Pixel Cup) 素材を `tools/build_sprites.py` で合成したもの。
元素材は `lpc/` フォルダに保存してある。

- 入手元: [Universal LPC Spritesheet Character Generator](https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator)
- ライセンス: **CC-BY-SA 3.0** / GPL 3.0（デュアルライセンス）
- **公開時はクレジット表記が必須。**

## 表記义務について

LPC素材は多人数の作者による共同作品。公開ビルドには以下を含めること:

1. タイトル画面またはクレジット画面に
   「Character sprites: Liberated Pixel Cup (CC-BY-SA 3.0)」の一文とリンク
2. 使用した各シートの作者一覧 → **抜粋済み: [lpc/CREDITS.csv](lpc/CREDITS.csv)**（該当11行）
   対象ファイル:
   - body/bodies/male/*（light, olive, brown, black）
   - head/heads/human/male/*
   - torso/clothes/longsleeve/longsleeve/male/white
   - legs/pants/male/white
   - feet/shoes/male/black
   - hair/plain/male, hair/buzzcut/adult, hair/natural/adult

作者（使用シート分・CREDITS.csv より）: Stephen Challener (Redshrike),
Johannes Sjölund (wulax), Eliza Wyatt (ElizaWy), bluecarrot16,
Benjamin K. Smith (BenCreating), JaidynReiman ほか。
正確な行単位の帰属は同梱の lpc/CREDITS.csv を参照。
